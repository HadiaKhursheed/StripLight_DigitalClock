While making the clock on different stages different codes are uploaded to it for testing. \
The WS2812B led strips can be testing on the WLED app easily. But in our project we need it to work with Arduino IDE so we can make it work like a clock display. \
The codes provided are to be uploaded on Arduino IDE & Board used is NodeMCU (ESP8266). \
**strip_light_test_code.ino** is used to check the working of the LED strip. Though this leds on the srtip light up one by one in random colors. \
**strip_light_test_code.ino** is uploaded to check the clock's working after soldering the strips in desired manner. \
**strip_light_test_code.ino** is uploaded to test the clock with the webpage that can change colors over the Wi-Fi.
